# Tablo Tool

Программа для управления табло и автоматической работы с MySQL-базой очереди.

## Поддерживаемые режимы

### 1. RS-485 (gekata)
Используется для 4-символьных табличек, где команда отправляется напрямую в COM-порт.

Пакет 8 байт, отправляется 7 раз подряд:
```text
[F0, 00, ADDR, BLINK, D1, D2, D3, D4]
```

Где:
- `ADDR` — адрес табло `1..254`, кроме `240`
- `BLINK` — `10`, если мигание включено, `0`, если выключено
- `D1..D4` — 4 ASCII-символа, например `0104`

Очистка:
```text
[F0, 00, ADDR, 0F, 20, 20, 20, 20]
```

Смена адреса:
```text
[F0, FF, OLD, OLD, OLD, NEW, NEW, NEW]
```

### 2. COM табло (rek)
Используется для табло из старого комплекта `rek`, где `VideoServerHD`/`Com.exe` в итоге отправляют кадр в COM-порт.

Параметры линии:
- `1200 бод`
- `8N1`
- без flow control

Формат кадра:
```text
55 + 32 байта
```

Структура 32-байтного хвоста:
- 4 бита `mode`
- 4 бита единиц номера
- 4 бита десятков номера
- 4 бита сотен номера
- 8 бит `BCD(window_no)`
- 8 бит контрольного байта

Каждый бит кодируется так:
- `1 -> 7F`
- `0 -> 00`

Где:
- `window_no` — номер окна `0..99` из поля `Адрес`
- `number` — номер талона `0..999`
- `mode` — рабочий режим, по умолчанию `2`

Очистка выполняется тем же кадром, но вместо номера отправляется `FFF`.

## Требования
- Windows
- Для режима `RS-485` — USB/COM адаптер
- Для режима `COM табло (rek)` — доступ к COM-порту линии табличек
- Доступ к MySQL с правом чтения

## Файлы рядом с программой
После первого запуска рядом с `exe` используются:
- `tablo_settings.ini` — настройки приложения
- `tablo_map.ini` — карта соответствия `cabinet_id -> address`

Если `tablo_map.ini` отсутствует, программа создаёт его сама.

Пример:
```ini
[map]
1=33
2=34
3=35
```

Для режима `COM табло (rek)` справа в `tablo_map.ini` указывается не сетевой адрес, а номер окна `0..99`.

## Логика работы с БД
Используются только чтение и таблицы:
- `orders_list` — появление новой записи означает вызов талона
- `queue` — `finished=1` или `cancelled=1` означает очистку табло
- `operators` — связывает `orders_list.oper_id` с `queue.operator_id`

Программа ничего не пишет в БД.

## Как пользоваться

### Вкладка «Связь с БД»
1. Выберите `Режим табло`.
2. Выберите `COM-порт`.
3. Заполните параметры MySQL.
4. Нажмите `Старт`.

### Вкладка «Тест Табло»
- `Адрес`:
  - для `RS-485` — адрес табло
  - для `COM табло (rek)` — номер окна `0..99`
- `Текст/номер`:
  - для `RS-485` — 4 символа
  - для `COM табло (rek)` — номер талона `0..999`
- `Отправить` — тестовый вывод
- `Очистить` — погасить выбранное табло
- `Скан`:
  - для `RS-485` — обычный скан адресов
  - для `COM табло (rek)` — автоматический перебор номеров окон по диапазону
- `Смена адреса` — только для режима `RS-485`
- `Перезагрузить` — перечитать `tablo_map.ini`

### `tablo_map.ini`
Логика одинаковая: слева `cabinet_id` из БД, справа — идентификатор табло для выбранного режима.

Примеры:
```ini
[map]
1=33
2=34
```

- в `RS-485`: `33`, `34` — адреса табло
- в `COM табло (rek)`: `33`, `34` — номера окон

### Автоповедение
- При запуске программа автоматически пытается стартовать мониторинг БД.
- После запуска окно сворачивается в трей.
- При закрытии программа отправляет команду очистки табло.

## Сборка
Готовый файл запуска:
```text
dist\tablo_tool.exe
```
