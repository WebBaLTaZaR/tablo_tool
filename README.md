# Tablo Tool

Программа для управления табличками по RS‑485 и автоматической работы с БД очереди.

## Для каких табло подходит
Поддерживается **протокол, который используется в проекте `gekata`**:

Пакет 8 байт (отправляется 7 раз подряд):
```
[0xF0, 0x00, RS_ADDR, BLINK, D1, D2, D3, D4]
```
- `RS_ADDR` — адрес табло (1..254, кроме 240)
- `BLINK` — 10 (мигать) или 0 (не мигать)
- `D1..D4` — ASCII символы (например `0001`)

Очистка:
```
[0xF0, 0x00, RS_ADDR, 0x0F, 0x20, 0x20, 0x20, 0x20]
```

Смена адреса:
```
[0xF0, 0xFF, OLD, OLD, OLD, NEW, NEW, NEW]
```

## Требования
- Windows
- USB‑RS485 адаптер (COM‑порт)
- Доступ к MySQL (только чтение используется)

## Запуск
Запускается файл:
```
dist\tablo_tool.exe
```

## Файл карты адресов
В папке с EXE создаётся файл `tablo_map.ini`.
Карта формата:
```
[map]
1=33
2=34
3=35
```

Где:
- ключ = `cabinet_id` из БД
- значение = адрес табло на RS‑485

## Логика работы с БД (только чтение)
Используются таблицы:
- `orders_list` — появление записи = **вызов** (табло загорается)
- `queue` — `finished=1` или `cancelled=1` = **гасим табло**

Соответствие оператора:
- `orders_list.oper_id` соответствует `operators.operator_id`
- `queue.operator_id` соответствует `operators.id`

## Как пользоваться
### Вкладка «Связь с БД»
1. Выберите COM‑порт.
2. Укажите параметры БД.
3. Нажмите **Старт**.

### Вкладка «Тест Табло»
1. **Адрес** и **Текст** → кнопка **Отправить**.
2. **Очистить** — гасит выбранный адрес.
3. **Скан** — последовательно шлёт по диапазону адресов.
4. **Смена адреса** — изменяет адрес табло.
5. **Перезагрузить** — перечитать `tablo_map.ini`.

## Важно
- Программа **не вносит изменений в БД** (только SELECT).
- Таблички должны быть на одной RS‑485 линии.
